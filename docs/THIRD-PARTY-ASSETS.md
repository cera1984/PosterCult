## Original 16 Pro shell build tooling

The generated iphone-16-pro-shell.glb is original MIT geometry, built with three-bvh-csg 0.0.17 and three-mesh-bvh (both MIT), using the existing Three.js MIT dependency. These build tools are not shipped to the browser. Sources and limitations: IPHONE-16-PRO.md.

## Cinema CC0 props (2026-10-27)

Seven models from [Abandoned Cinema and Projection Booth](https://3dassets.dev/packs/abandoned-cinema-and-projection-booth), by 3D Assets, released under [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/): Film Projector, Projector Pedestal, Auditorium Seat, Curtain Panel, Film Reel, Popcorn Machine and Concession Counter. Source explicitly declares AI generation (GPT-6). These are stylized designs, not historical scans. Individual source URLs, hashes, byte counts and source triangle counts: `assets/cinema/manifest.json`. The original GLBs are unchanged; runtime changes include burgundy fabric/sheen, green enamel, brass/wood palette, instanced seating and curtain movement. Files are self-hosted; the site makes no requests to the provider. Public credits: `docs/cinema-models.html`.

The previously researched Sketchfab models were not integrated: their official download API requires separate authentication (401). No protected viewer files were extracted. These directly downloadable CC0 alternatives were selected and visually inspected instead.
